# Cloud Cost & License Optimization Dashboard

An end-to-end cloud cost and license optimization analytics project built using AWS, Azure, Snowflake and Microsoft Power BI.

## 📌 Project Overview

This project analyzes cloud infrastructure costs, resource utilization, software license spending, unused licenses, and actual vs forecasted cloud costs.

The objective is to identify cost leakage, underutilized resources, unnecessary software licenses, and areas where cloud spending can be optimized.

## 🎯 Business Objectives

- Analyze cloud infrastructure spending
- Identify high-cost cloud services
- Monitor CPU and memory utilization
- Identify overutilized servers
- Analyze software license spending
- Identify unused software licenses
- Compare actual cloud cost with forecasted cost
- Identify cost variance
- Support data-driven cloud cost optimization decisions
